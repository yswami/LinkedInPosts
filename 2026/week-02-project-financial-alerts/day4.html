    Implementation pattern

    Simulate before recommending.

    01

    Map

    Identify shared people, milestones, contracts, dependencies, and downstream projects.

    02

    Simulate

    Calculate cost, schedule, cash-timing, and capacity effects using governed scenario logic.

    03

    Compare

    Show options against the same portfolio metrics instead of optimizing one project in isolation.

    04

    Govern

    Expose assumptions, constraints, decision rights, and approvals before any resource change.

    A simulation is not a prediction or an execution approval.

    All figures and relationships are fictional. Real portfolio effects must come from governed project, resource, contract, billing, and financial data—not an LLM-generated dependency graph.
