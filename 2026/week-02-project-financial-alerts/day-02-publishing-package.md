## Suggested video title

A fixed 5% threshold is not an alert strategy

## Video accessibility description

A narrated Project Meridian example holds a validated 10% cost variance constant while changing contingency, persistence, time to act, and contractual consequence. The same signal is shown as a monitoring case in one context and an escalation case in another. The animation concludes that deterministic policy should classify the response while an LLM explains and routes it.

## First comment

In the experiment, compare these two presets:

1. “Monitoring context”: the variance is covered by recognized contingency, appears for the first time, and has a long response window.
2. “Escalation context”: residual exposure remains, the variance persists, the response window is closing, and a contractual commitment is affected.

The reported variance stays at +10%. Only the decision context changes.

What dimensions would your organization require before interrupting a project manager, controller, sponsor, or portfolio leader?
