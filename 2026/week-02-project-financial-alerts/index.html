Why

    Day 1 boundary: validate the financial signal. Whether it is important enough to alert is a separate policy decision for Day 2.

    Implementation pattern

    Separate the number from the evidence behind it.

    01

    Calculate

    Start with the deterministic financial position: budget, actuals, ETC and reported EAC.

    02

    Validate

    Check timestamps, pending transactions, commitment treatment, currency and forecast version.

    03

    Classify

    Return a validated signal or a data-validation request. Do not let an LLM invent the status.

    04

    Explain

    Use AI to communicate the range, unresolved evidence and appropriate next step.

    This lab deliberately stops before alerting.

    It teaches signal validation, not a universal threshold. All values and rules are fictional and illustrative.
