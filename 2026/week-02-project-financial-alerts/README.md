# Week 02 · When AI Agents Touch Project Money

A five-day, fictional Project Meridian story about financially governed autonomy in enterprise project portfolio management.

## Day 1 · Is the overrun real?

- Read the [LinkedIn-ready post](day-01-linkedin-post.md).
- Run the [Project Financial Alert Lab](https://yswami.github.io/LinkedInPosts/2026/week-02-project-financial-alerts/).
- Watch the [60-second narrated story](https://yswami.github.io/LinkedInPosts/2026/week-02-project-financial-alerts/day1-story.html).
- Upload [`media/project-financial-alert-day1-60s.mp4`](media/project-financial-alert-day1-60s.mp4) with [`day-01-captions.srt`](day-01-captions.srt) to LinkedIn.

The Day 1 experiment separates a reported financial number from the evidence behind it. It returns either `VALIDATE DATA` or `VALIDATED SIGNAL`; it does not teach a universal financial-alert threshold.

## Planned story arc

1. Validate the financial signal.
2. Configure materiality and alert policy.
3. Explain uncertainty without false precision.
4. Simulate the portfolio blast radius.
5. Define the agent’s permitted action and approval boundary.

## Run locally

No build step or external dependency is required:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/2026/week-02-project-financial-alerts/` from the repository root.

All examples, values, thresholds, and project names are fictional and educational. They do not contain customer data or represent documented product behavior.
