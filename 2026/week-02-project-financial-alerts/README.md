The Day 5 experiment replays the complete Meridian case and then makes the reader configure the agent's authority per action. Governed execution requires recorded authority, transaction-level revalidation, audit, and recovery controls.

## Story arc

1. Validate the financial signal.
2. Configure materiality and alert policy.
3. Explain uncertainty without false precision.
4. Simulate the portfolio blast radius.
5. Define the agent’s permitted action and approval boundary.

## Run locally

No build step or external dependency is required:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000/2026/week-02-project-financial-alerts/` from the repository root.

All examples, values, thresholds, and project names are fictional and educational. They do not contain customer data or represent documented product behavior.
